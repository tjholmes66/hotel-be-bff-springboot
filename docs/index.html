Hotel Management System — BFF

This is the opening project of a Hotel Management System. This repository contains the BFF (Backend-For-Frontend), written in Java and Spring Boot.

Architecture

The system is composed of independently deployable frontends and a set of domain-driven microservices:

  • Frontends — separate applications capable of being deployed on their own, written in Angular and/or React.
  • Microservices (domain-driven design): housekeeping, frontdesk, kitchen, maintenance.

Technology Stack

  • Communication: Apache Kafka between services.
  • Authentication: Keycloak, running in a Docker container.
  • Database: MySQL Server in its own schema, already in a Docker container.
  • Runtime: all parts reside in Docker containers, with Kubernetes used to allow the services to be discovered.
  • Database migrations: Flyway, shared across each microservice.
